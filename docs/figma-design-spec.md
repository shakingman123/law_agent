# 前端界面设计规范（Figma 复刻指南）

> 本文件配合高保真原型 docs/ui-mockup/index.html 使用，可直接在 Figma 中复刻或由 Codex（连接 Figma 后）自动生成。
> 原型 4 个页面：工作台 / 日程列表 / 文档库 / 设置。

## 1. 设计令牌（Design Tokens）

### 颜色
| Token | 色值 | 用途 |
|---|---|---|
| Primary | #1D4ED8 | 主按钮、激活态、链接 |
| Primary-Hover | #2563EB | 按钮 hover |
| Primary-Bg | #EFF4FF | 选中底色、浅色强调 |
| Background | #EEF2F7 | 页面内容区底色 |
| Panel | #FFFFFF | 卡片、侧栏、输入区 |
| Border | #E3E8EF | 边框、分隔线 |
| Text | #0F172A | 主文字 |
| Muted | #64748B | 次级文字 |
| Danger | #DC2626 | 紧急提醒、删除 |
| Amber | #B45309 | 二审/待办/未解锁 |
| Green | #059669 | 成功、私库标签 |
| Sidebar-Bg | #F8FAFC | 左侧列表栏底色 |

### 字体
- 字体族：PingFang SC / Microsoft YaHei / Segoe UI（中文优先系统字体）
- 标题 18–20 Bold；小标题 14–16 Semibold；正文 14 Regular；辅助 12 Regular；标签 11 Medium

### 圆角 / 阴影 / 间距
- 圆角：按钮 8、卡片 10–12、弹窗 14、胶囊标签 12
- 阴影：卡片 `0 1px 3px rgba(15,23,42,.08) + 0 8px 24px rgba(15,23,42,.06)`；弹窗 `0 24px 64px rgba(15,23,42,.30)`
- 间距基准 4px：8 / 12 / 14 / 16 / 18 / 22 / 24 / 26

## 2. 画布设置

- 页面尺寸：1440 × 840（每页一个 Frame）
- Figma 文件结构建议（每页一个 Frame）：
  - Page 1「工作台」：`工作台 / 新增案件弹窗 / 模板下拉`
  - Page 2「日程列表」：`日程列表(周) / 新建日程弹窗`
  - Page 3「文档库」：`密码门禁 / 文档库列表 / 未解锁弹窗`
  - Page 4「设置」：`基本信息 / 界面设置 / 公司`
- 建议建立组件库：Button(Primary/Ghost/Danger)、Tag、CaseCard、MsgBubble、Modal、Input、Textarea、Select、Switch、Avatar、TplMenuItem

## 3. 工作台布局（1440×840）

```
┌─────────┬──────────────────────────────────┬──────────┐
│ 224 侧栏 │  中央对话框（自适应）            │ 288 案件栏│
│  LOGO    │ 56 顶栏：模板下拉 + 新建案件     │ 折叠按钮  │
│  日程    │ 消息流（气泡/表单卡/文书预览）   │ 案件卡片×4│
│  文档库  │ 输入区（附件+输入框+发送）       │ 新增案件  │
│  模板    │                                  │          │
│  用户卡  │                                  │          │
└─────────┴──────────────────────────────────┴──────────┘
```

关键组件规格：
- 左侧栏 224px：#F8FAFC，导航项高 38，激活态 Primary-Bg 圆角 8；底部用户卡 38px 头像 + 姓名 + 公司 + 齿轮按钮
- 顶栏 56px：模板下拉按钮（Border 描边胶囊）；右侧「当前案件」灰标签 + 主按钮「＋新增案件」
- 消息气泡：Agent 白色（左圆角 4），User 主色（右圆角 4），最大宽 760；Agent 消息含工具卡片（信息表单 / 文书预览）
- 文书预览卡：A4 纸样式（宋体正文、标题居中、此致/落款右对齐），底部「微调重写 / 确认生成」双按钮
- 案件栏 288px：标题「案件 最近1周打开」+ 折叠/新增图标；案件卡 10 圆角，激活态 Primary 描边；底部提示「仅显示最近1周」
- 新增案件弹窗 520px：案件名称/原告/被告/管辖法院/基本情况 必填（红星标记）

## 4. 日程列表布局

- 顶栏：标题 + 日/周/月切换（分段控件）+ 今天 + 新建日程
- 主区：周视图网格（56px 时间列 + 7 天列），事件卡按紧急度着色：红=举证期/上诉期（提前1天）、琥珀=一般期限（提前5天）、蓝=会议
- 右侧 300px：待办提醒列表 / 通知渠道开关（飞书✓ 微信✓ 钉钉—）/ 提醒规则说明

## 5. 文档库布局

- 门禁态：居中锁图标 + 标题 + 密码输入框 + 主按钮
- 列表态：顶部搜索栏（🔍 + 输入框）+ 筛选（全部/私库/公库）
- 案件卡：标题 + 更新时间 + 标签（协作=蓝、私库=绿、未解锁=琥珀）+ 文件类型图标行（docx/pdf/图片/视频）
- 未解锁弹窗：两个选项卡（查看脱敏版 / 向经手律师申请）

## 6. 设置布局

- 左侧 200px 子导航：基本信息 / 界面设置 / 公司
- 基本信息：头像 + 姓名/邮箱/手机号/职级表单 + 保存
- 界面设置：字体大小（小/中/大）+ 背景色（浅灰/米白/深色/护眼绿色板）+ 主题预览小卡
- 公司：当前公司 + 退出；邀请码输入 + 申请加入；管理员入口

## 7. 在 Figma 中生成

连接 Codex 桌面端的 Figma 授权后，可让 Codex 用 use_figma 按以上规范直接生成这 4 个页面（Frame 1440×840 + 组件库 + 变量），无需手绘。
