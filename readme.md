# 法律文书agent #
**作为一个法律文书agent，可以实现法律条文、法律案列的查找；保存案件相关的电子资料进入云文档；输入相关信息自动编写法律文书（起诉状、上诉状、答辩状等等）；关键时间节点的提醒（不服判决的上诉期限、不服裁定的上诉期限自动加入日程**

## 前端的交互页面 ##
前端的交互界面链接agent的多个功能，具体的排版布局如下：
### 工作台 ###
工作台作为主界面，主要实现的功能是**撰写法律文书**，其他的功能都可以从工作台界面进行跳转。
1. **对话框：** 对话框占工作台的中心部分，完成**撰写法律文书**、**法律条文、案列的查找**、**关键时间节点提醒**等功能。用户可以在对话框的下拉选项中选择自有模板还是通用模板，自有模板可以通过word或者pdf文件上传，自由模板处会保存上传的模板，收藏的模板可以排在前面。用户可以在对话框中输入“帮写一份上诉状”、“帮我写一份答辩状”——agent调用相应的模板——确定案件名称——若缺少信息向用户进行询问——用户提交信息——agent生成文书的预览件——用户确认后生成。
2. **显示案件栏：**工作台的交互形式是对话框，右侧有供选择的案件，使用人员可以随时切换需要工作的案件。右侧的显示案件栏，仅显示最近1周打开的案件，右侧的显示案件栏可以选择折叠或者展开。在显示案件栏可以新增案件，点击新增案件，可以填入案件的基本信息。其中必填项有原告、被告信息、上诉法院信息、案件基本情况等等。
3. **列表栏：**工作台的左侧是列表栏，比较简略，包括日程列表、文档库（私库和公库），点击跳转到相应界面。
4. **设置界面：** 在工作台的左下侧、列表栏的下面，显示用户的名称和公司。点击头像进入到设置界面。
### 日程列表 ###
- 跟飞书的日程列表相似，可以显示日安排、周安排和月安排，用户可以在该界面新建日程也可以在对话框新建日程。
- 通知形式，若用户正在使用该平台，在平台上进行提醒。于此同时，可发送飞书、微信、钉钉等消息提醒，在该界面可以设置接入，公司的管理员也可以统一接入。
### 文档库 ###
- 从工作台点击跳转如文档库需要输入个人密码，进入后可以看到私库的所有案件，案件以更新时间进行排序，每一个案件里面包括该案件的所有信息，不限于文档、PDF、照片、视频等等。
- 文档库的上方是搜索栏，可以输入案件的关键信息进行搜索，搜索结果包括私库和公库的案件，非自己职级所能看见的案件，后面会标记未解锁。点击未解锁案件，有两种方案，一种是看脱敏后、阉割版的文件（仅上诉书、判决书，不包括证据）；另一种是向案件的经手律师申请。
- 某一个案件为几个律师合作办理的，都有阅读、添加、修改文件的权限，同时也有同意他人加入协作或者审判他人的阅读申请的权限。
### 设置界面 ###
- 基本信息的修改和添加。修改名字，添加邮箱、手机号，都可以在设置界面进行修改。
- 界面信息的修改。修改字体和背景颜色
- 加入和退出公司。填入公司管理者发送的邀请码，申请进入公司，管理者审批后，加入成功。



## 法律条文、案列的查找 ##
参考资料来源：
1. 严格的法律条文，包括《民法典》、《刑法》等等；
2. 司法解释和司法判例；
3. 公司脱敏后的案列；
4. 公众号上的相关观点。
输出形式：
1. 一个问题所引用的参考资料不超过10个；
2. 总分的形式进行输出；
3. 有对比观点的通过表格的形式进行对比输出；
4. 引用的参考资料可以点击跳转。

## 保存案列的电子资料 ##
加密文档库
- 使用人员可将加密文档存入云文档或硬盘中，支持的云文档包括百度网盘、夸克网盘等等；
- 通过交互界面可以在查找之前保存的云文档，查找时需输入密码；
- 所有的文档按照案件的形式进行储存

公司库
- 加入公司的使用人员，其加密文档库与公司库绑定；
- 上级可以查阅下级的文档库，使用自己的文档库密码即可；
- 公司库当中的判决案列进行脱敏后进入到参考数据的数据库中

## 撰写法律文书 ##
1. 选择自有模板或者是提供的通用模板；
2. 自动导入案件的相关信息，包括上诉人、上诉人律师、上诉请求等等（根据不同的法律文书，提示需要的输入信息），这些信息在建档时已经被记录；
3. 预览生成的文书word，不满意可以进行微调，确认后保存到本地和文档库；
4. 发到法院邮箱并寄出快递

## 关键时间节点提醒 ##
- 当新的案件接手以后，案件可能涉及到一审二审，存在不同的时间节点需要注意，包括答辩期与管辖权异议、举证期限、上诉期等等
- 通过发送微信消息或者飞书消息的形式提前通知律师，根据不同事项的紧急程度，可分为提前5天提醒或者提前1天提醒等等。
